# Samples de Bandoneón

Este directorio debe contener archivos de audio (.mp3, .wav, .ogg) con samples de bandoneón reales.

## Estructura de archivos requerida:

```
samples/
├── C3.mp3
├── D3.mp3
├── E3.mp3
├── F3.mp3
├── G3.mp3
├── A3.mp3
├── B3.mp3
├── C4.mp3
├── D4.mp3
├── E4.mp3
├── F4.mp3
├── G4.mp3
├── A4.mp3
├── B4.mp3
└── C5.mp3
```

## Fuentes recomendadas para samples libres:

1. **Freesound.org** - Samples gratuitos con licencia Creative Commons
2. **Zapsplat** - Biblioteca de efectos de sonido
3. **BBC Sound Effects Library** - Samples gratuitos de la BBC
4. **Philharmonia Orchestra** - Samples de instrumentos orquestales
5. **University of Iowa Electronic Music Studios** - Samples de instrumentos

## Características técnicas recomendadas:

- **Formato**: MP3 (320kbps) o WAV (44.1kHz, 16-bit)
- **Duración**: 2-4 segundos por nota
- **Tipo**: Notas sostenidas limpias sin vibrato excesivo
- **Rango dinámico**: Grabaciones con buen rango dinámico
- **Ruido**: Mínimo ruido de fondo

## Notas sobre licencias:

- Asegúrate de que los samples tengan licencias apropiadas para uso en aplicaciones web
- Considera usar licencias Creative Commons o samples de dominio público
- Documenta la fuente y licencia de cada sample

## Fallback automático:

Si no se encuentran samples, el sistema automáticamente usará síntesis como fallback para mantener la funcionalidad.
